# Maven, JUnit 5, and GitHub Actions Lab

## Team members
- Matthew Davi

## Description
A Java Maven project that calculates a right triangle's hypotenuse.
JUnit 5 verifies the calculation.

## Run tests
Requires JDK 17 or newer and Maven.

Run:
mvn clean test

GitHub Actions automatically builds the project and runs the JUnit tests on pushes to main.
